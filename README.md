## Objectives
Computational social science requires students to wrangle complex data structures and use statistical methods to find and test patterns in them—all while writing reproducible code in collaborative environments. Because our incoming Master 2 students come from different academic backgrounds (engineers, social sciences, applied math), the goal of this one-week camp is to get everyone on the same page before regular classes start in October. The camp focuses on setting up software, teaching basic coding hygiene, overviewing some statistical basics, and introducing some of the tools and topics students will encounter throughout the year. The material will be hands-on, accessible, and tailored to students' skill levels.

SQD students will also find the bootcamp useful and are highly encouraged to participate.
